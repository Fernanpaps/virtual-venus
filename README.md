# virtual-venus

Blog personal hecho con Astro siguiendo el tutorial oficial "Build your first Astro Blog" (Units 1 a 6).

Sitio publicado: https://astrofernnadoleon.netlify.app

## Qué incluye
- Unit 2: páginas .astro, posts en Markdown, contenido dinámico, estilos por página y globales
- Unit 3: componentes (Header, Navigation, Hamburger, Footer, Social) y script para el menú
- Unit 4: layouts (BaseLayout y MarkdownPostLayout anidados)
- Unit 5: lista automática de posts con import.meta.glob, páginas de etiquetas con getStaticPaths y feed RSS
- Unit 6: isla interactiva con Preact (Greeting) y botón de modo claro/oscuro

## Comandos
- `npm install` — instala dependencias
- `npm run dev` — servidor local en localhost:4321
- `npm run build` — genera el sitio en ./dist/
